# CalicoPet v0.3.2

发布日期：2026-11-21

本次是稳定性、交互手感与发布质量更新，没有改变既有三花猫的形象比例与配色，也没有扩展番茄钟、养成或 AI 功能。

## 移动残影与抽搐修复

- 统一使用 Windows **内容区坐标**定位透明小窗，不再混用窗口外框坐标和网页内容坐标。
- 窗口背景和四角完全透明，关闭圆角与厚边框效果。
- 每次原生位置报告携带单调递增的 `seq`；渲染器先按最新目标位置绘制，过期回传直接忽略，不再把旧位置重画到新一帧。
- 修复快速漫游、跟随、反向拖拽和 150% DPI 下的双影、矩形残底与来回抽动。
- 自动回归中 `window-sync` 最大位置偏差为 1px；开发版在白色背景上的真实鼠标连续拖拽未再出现旧版矩形残底。

## 高 DPI 与多显示器

- 新增“自动选择显示器”和“固定到指定显示器”。
- 自动模式综合保存位置、当前窗口、鼠标位置和主显示器选择工作区；失效显示器自动回退主屏。
- 漫游保持在单个工作区，跟随按鼠标所在屏切换，拖拽按真实指针位置更新工作区。
- 显示器增删、DPI 或工作区变化后重新夹取窗口与渲染位置，避免宠物遗留在屏幕外。

## 手势与暂停

- 单击摸头、双击生气、拖拽携带改为互不重复触发的手势识别。
- 移动超过 `6 × devicePixelRatio` 或长按约 180ms 才进入拖拽。
- 拖拽结束、取消、失焦和看门狗结束不再误算成单击。
- 暂停会清理待定点击和拖拽；暂停时的托盘摸头直接忽略。

## 低打扰与电源策略

- 托盘和宠物右键菜单新增“隐藏桌宠 / 显示桌宠”。
- 隐藏、锁屏和系统休眠期间停止运动循环；恢复时重置计时，避免恢复瞬间大步跳帧。
- 隐藏时停止跟随模式的全局鼠标轮询；第二次启动请求或托盘左键可恢复隐藏实例。
- 新增“电池供电时省电”选项：电池供电且开启时，运动更新目标由 60Hz 降为 30Hz。
- 隐藏、锁屏和休眠是独立运行时状态，不覆盖用户保存的暂停设置。

## 原生透明区域穿透

- Windows 上使用 `BrowserWindow.setShape` 设置原生窗口轮廓，不再依赖容易卡住的全局忽略鼠标开关。
- 当前帧遮罩按横向连续区段合并为矩形；主进程校验、裁剪并限制数量，异常时恢复完整窗口。
- 仅在轮廓、倍率或明显形变变化时更新，保留 2px 安全边距，避免 DPI 舍入、呼吸和落地挤压裁掉边缘。
- 已通过 Windows `WindowFromPoint` 原生命中测试：猫身体命中桌宠，透明角落落到后方窗口。

## 桌宠边缘异常像素

- 按用户建议，全部 33 帧在最终栅格上统一为**单层、连续的深黑色外描边**，不再依赖局部删点；八邻域外扩补齐斜角连接，每帧的外轮廓均为一个四连通整体。
- 先移除旧外环再生成统一轮廓，尾巴不再预涂 exposed 深边；外描边仅作用于与画布外部连通的区域，不在腿脚之间的封闭空隙补黑点。内部毛色、五官和浅色胡须保持不变。
- 运行时改用原生 76×68 `@1x` PNG，同步时校验每张 PNG 的 IHDR 尺寸；主画布按整数物理像素绘制，避免 150% DPI 下额外插值。
- 根据实际窗口截图定位到**真实叠帧**：画布使用恒等设备像素变换，`clearRect` 却错误地再次除以 DPR，125%/150% 下右侧和底部未被清空。现在每次绘制直接清除完整 backing store，不再累积旧帧。
- 主画布与蒙版画布统一使用 CPU 像素光栅化，避免 GPU/CPU 在非整数倍最近邻采样时选择不同源像素；专项在每次实际绘制的同一时刻生成干净参考副本，要求残留、缺失、变色和总差异像素全部为 0。
- 双姿态真实画布专项实际捕获 `sit_0.png` 与 `carry_4.png`：源尺寸均为 76×68，DPR=1.5，外轮廓数量均为 1，外露非描边像素、内部黑点与短碎描边均为 0，非透明像素 alpha 均为 255，调色板外颜色为 0。

## 配置与恢复

- 新增独立配置核心模块，集中处理字段校验、`configVersion: 1` 迁移、原子保存和损坏恢复。
- 保存已知良好备份 `pet-config.json.bak`；主配置损坏时优先从备份恢复。
- 损坏主文件保留为带时间戳的 `.corrupt` 文件，不直接删除。
- 渲染进程非正常退出时，一分钟内最多自动重载两次；正常退出不触发恢复。

## 素材与性能

- 发布使用的 7 组、33 帧原生动画均为 76×68 PNG，统一连续外描边后总计 45,129 字节；不做无收益的重压缩。
- 主画布复用同帧、同朝向、同倍率的遮罩位图，避免重复缩放和镜像源图。
- 最新性能专项采样：正常运动 60 次循环、7 次遮罩构建、7 次轮廓更新、60 次位置报告；省电采样 23 次循环；暂停时计数保持稳定。

## 验证结果

- TypeScript 构建、源码文本与敏感路径检查通过。
- 配置核心 4 项 Node 单元测试通过。
- 开发版完整行为矩阵 **31/31** 通过，含窗口贴合、高 DPI、快速漫游、拖拽、手势、显示器、原生形状、坐姿与携带双姿态真实画布像素、崩溃恢复、性能和电源状态。
- **便携版完整行为矩阵 31/31 通过**；安装包通过隔离的静默安装 → 启动冒烟 → 静默卸载全流程。
- 隔离桌面在 100% DPI 下完成原生命中、真实拖拽、隐藏/恢复和菜单退出验证；主测试环境为 150% DPI。
- 本机自动化只发现一块物理显示器；真实双屏热插拔与混合 DPI 仍需人工验收。
- 电池、锁屏和休眠通过受控状态模拟验证，尚未完成真实拔电、锁屏和睡眠硬件测试。
