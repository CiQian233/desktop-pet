# CalicoPet v0.2.0 更新日志

> 发布日期：2026-10-25
> 本版本为**纯优化版本**：不新增功能、不改变任何现有行为，全部改动围绕渲染性能、代码卫生与工程化护栏。

## 一句话总结

渲染主循环三项优化使待机 CPU 下降约六成（打包版实测 43.5% → 17.1% 单核），同时清理死代码、封堵"陈旧资源进包"与"无测试出包"两类工程隐患。

---

## 性能优化（渲染主循环）

1. **命中掩码缓存键修正**：掩码缓存键此前混入窗口局部坐标，而掩码本身是精灵局部空间、与位置无关——导致漫游/拖拽/跟随期间**每帧**执行一次 `getImageData` 全像素读回与扫描。现在键仅由 `帧 | 朝向 | 倍率` 构成，移动期间零重建。
2. **脏标记绘制**：此前每帧无条件清空并重绘画布（60fps，暂停时也照画）。现在只有 帧 / 位置 / 朝向 / 倍率 / 呼吸 / 压扁 / dpr 任一变化时才重绘；待机时绘制次数降至动画帧率，**暂停后为零**（画面保持最后一帧，与原有"纯冻结"语义一致）。
3. **掩码画布复用与单次镜像绘制**：掩码栅格化此前每次重建都新建离屏画布、镜像帧需要画两次；改为复用模块级画布并单次镜像绘制。

### 实测数据（单核百分比，20 秒采样，含全部 Electron 子进程）

| 场景 | v0.1.0 | v0.2.0 | 变化 |
| --- | --- | --- | --- |
| 待机 rest（**新旧打包版直接对测**） | 43.5% | 17.1% | **−61%** |
| 待机 rest（开发构建） | 59.9% | 13.6% | −77% |
| 漫游 roam（开发构建） | 56.7% | 40.0% | −29% |
| 跟随 follow（开发构建） | —（未测） | 27.1% | 本次新增测量 |

## 死代码与陈旧契约清理

- 删除 `src/shared/layout.ts`（75 行）：全仓库零引用、不参与任何 tsconfig 编译，常量停留在旧值 72×68（实际 76×68），IPC 频道名与实际实现不符——整屏覆盖层旧架构的遗留物。
- 删除 `pet:wake` 死通道整条链路（preload 的 `onWake`、渲染器接线、控制器的 `wake()`）：主进程从不发送该事件，链路永不触发。
- 删除只写不读的 `Channel.reason` 字段及配套 `Reason` 类型与 `TRANSIENT` 映射表。
- 清理 `void wasChasing` / `void spriteW` / `void local` 等压制参数残留，修正两处误导性注释（`breathing` 变量挂着别处的注释、`inputreport` 探针注释引用了不存在的脚本）。

## 构建与工程化

- **sync-assets 复制前清空帧目录**：此前只增不删，重命名/删除动画后的陈旧帧会一直留在 `dist` 并随 electron-builder 打进 exe（本次实测清出 1 个历史残留帧）。
- **新增"尺寸常量一致性"构建守卫**：`meta.json` 的原生尺寸（76×68）与 `main.ts` / `smoke.ps1` / `verify-behaviour.ps1` 三处硬编码在每次构建时对齐；重新导出美术后若忘了同步测试脚本，构建立即失败（已做正、反向验证）。
- **CI 发版门禁**：`release.yml` 在打包前新增三步——文本守卫（含反向自测：注入乱码/丢引号必须被拒并点名）→ 完整构建 → 冒烟自检。此前打 tag 即出包，测试只存在于本地。
  - 注：smoke 步骤在 GitHub windows runner 上的首次运行尚未实测（本地仅做 YAML 解析校验），首次触发 workflow 时请留意该步骤。
- **smoke.ps1 无日志诊断**：无日志输出时附四类原因提示（单实例锁 / 权限拦截 / 受限沙箱 / 未构建），区分"根本没启动"与"启动后崩溃"。
- **displayId 配置加固**：读取持久化配置时对 `displayId` 增加 `Number.isFinite` 校验，NaN 不再放行。

## 升级说明

- 配置文件（`%APPDATA%\CalicoPet\pet-config.json`）完全兼容，无需任何迁移。
- **便携版用户**：下载 `CalicoPet-portable-0.2.0.exe` 双击即用；快捷方式指向旧版 exe 的，把目标改到新文件即可。
- **安装包用户**：运行 `CalicoPet-setup-0.2.0.exe` 可自选安装目录，会创建桌面/开始菜单快捷方式（名称「桌宠猫咪」）；从 0.1.0 直接覆盖安装即可，配置沿用。也支持静默安装：`CalicoPet-setup-0.2.0.exe /S /D=<安装目录>`。
- 已知未修（与本次改动无关，v0.1.0 即如此）：`hitgrid` 诊断探针的 `ok` 判定阈值未跟上 76×68 画布的剪影/包围盒关系；该探针不属于回归套件，不影响功能。
