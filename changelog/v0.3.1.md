# CalicoPet v0.3.1 更新日志

> 发布日期：2026-10-31
> 本版本只修复快速移动时的抽搐/抖动，不新增功能。

## 问题

用户反馈：走路速度调到“快”，或拖动速度过快时，桌宠会抽搐。

真实 Windows 鼠标轨迹复现确认了两个独立根因：

1. **快速漫游：窗口按 120ms 批量跳动**
   - 静止跟随使用的“2% 死区 + 120ms 节流”被错误地继续应用在运动中。
   - 快速漫游实测：窗口每 **120.9ms** 才移动一次，每次约 **31px**。猫的精灵在窗口内移动，窗口再周期性追赶，视觉上就是规律性抽搐。
2. **快速拖拽：窗口移动反过来污染指针坐标**
   - 指针位置由 `clientX/clientY + 窗口原点` 计算。
   - 窗口为了跟随猫而移动时，Windows 会为“实际没有移动”的光标合成新的鼠标事件；新的 client 坐标又被当成真实拖动位移，形成反馈环。
   - 真实快速拖拽复现：光标持续单向移动时，原生窗口出现 **16 次方向反转**，其中 **7 次无法用光标方向解释**，单步最大跳变 **192px**。

## 修复

### 指针输入改为绝对屏幕坐标

- `pointerdown / pointermove / pointerup` 改用浏览器提供的 `screenX / screenY`。
- 窗口自身移动不再改变指针读数，反馈环从数据源上被切断。
- 窗口合成的 `pointermove`（client 改变但 screen 坐标不变）会被忽略，不再刷新拖拽或“丢失指针”看门狗。

### 运动时逐帧跟随窗口

- 只有静止状态继续使用死区和 120ms 节流。
- `dragging / 漫游 / 跟随 / 腾空` 等真实运动状态下，窗口每帧向目标位置更新。
- 绘制使用主进程回报的 **真实窗口原点**，不再提前使用目标原点；避免一帧内猫画到窗口边缘之外再被拉回。

### 运动帧率明确限制为 60Hz

- 调度器不再直接跟随显示器刷新率。当前测试机 rAF 约为 165Hz，如果每次回调都移动窗口，会产生约 170 次/秒的 IPC 与原生 `setPosition`，反而饿死主进程和测试定时器。
- 改为定时器驱动的 60Hz 更新：运动帧 16.7ms，静止按动画 fps，暂停停止。
- 快速漫游实测：窗口移动间隔由 **120.9ms** 降至约 **17.7ms**，移动帧中位步长由 **31px** 降至 **5px**。

### 回归与测试隔离

- 新增 `smooth-roam-fast`：快速漫游回归，要求移动帧中位步长 `≤10px`，专门拦截 120ms 批量跳动回潮。
- 拖拽探针改为测量窗口“追平所需时间”，要求 `≤50ms`；实测通常 **19–34ms**。
- 快速拖拽探针故意塞入错误的 `clientX`（模拟 Windows 合成事件），只有使用 `screenX` 的实现才能保持 1:1。
- 测试模式忽略真实鼠标的 trusted pointer 事件，避免物理光标悬停在测试窗口上时覆盖探针轨迹。
- 测试用户目录继续通过 `PET_USER_DATA_DIR` 隔离。

## 一并包含：v0.3.0 的优化（未单独发布）

v0.3.0 没有单独发版，其全部改动都在本版本中。相对 v0.2.0 的主要提升（细节见 `changelog/v0.3.0.md`）：

- **按需渲染调度**：运动 60Hz、静止按动画帧率、暂停停止；12 秒采样下待机约 **5.1%** 单核（v0.2.0 日志记录为 13.6%，采样条件略有差异），慢速漫游 15 秒采样 **44.6% → 32.3%**。
- **动画由真实运动状态驱动**：漫游休息、跟随到达后不再原地播放走路循环；新增 `gait-anim` 用例。
- **统一坐标基准**：画布、绘制、像素命中共用一套变换，修复双重偏移与右下裁切；拖拽路径与窗口同步实测 **0px**。
- **物理与刷新率解耦**：抛出速度改为 px/s，落体阻尼与压扁回弹按时间计算，高刷屏手感一致。
- **配置副作用收敛**：位置持久化不再触发窗口 resize 与托盘菜单重建。
- **稳定性**：新增加载失败 / 渲染进程退出的日志与导航拦截；生产模式不再暴露 `window.__petTest`。
- **测试隔离**：`PET_USER_DATA_DIR` 隔离测试配置；行为矩阵 21 → 23 项（本版本为 24 项）。
