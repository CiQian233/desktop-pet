# CalicoPet v0.4.0

发布日期：2026-11-21

当前状态：**完整安装包与便携版已构建并完成本机发布验收。** 当前及后续版本日志统一使用 `changelog/vX.Y.Z.md` 命名。

## 1. 设置中心

- 新增独立设置窗口，包含「行为 / 声音 / 免打扰 / 性能 / 插件 / 外观 / 关于」七个分页。
- 原右键菜单中的模式、速度、倍率、开机自启、置顶、省电和显示器设置全部迁入设置中心；右键保留暂停、隐藏、设置和退出。
- 设置修改仍通过既有配置校验与持久化链，不改变漫游、跟随、手势和拖拽行为。
- 声音页只说明当前能力，不提供无效的音效开关；插件页只列出目录并支持打开目录，不伪称外部插件宿主已实现。

## 2. 气泡与台词系统

- 支持最多 12 个字符的猫咪名字，以及温柔、活泼、高冷三种性格。
- 支持清晨、午后、傍晚、夜晚的时段台词、启动迎接台词和随机闲聊。
- 随机闲聊默认约 3–5 分钟一次；移动、拖拽、暂停、隐藏、锁屏和休眠期间不主动闲聊。
- 「显示气泡」为总开关，关闭后立即隐藏并阻止后续气泡；「低频随机闲聊」可独立关闭。
- 气泡使用独立、置顶的透明穿透窗口，跟随猫咪位置并限制在工作区内，不扩大猫咪画布，也不抢占拖拽和点击。
- 新配置沿用既有原子保存、备份和损坏恢复机制；旧配置缺少新字段时使用默认值。

## 3. 更多自然动作

新增 7 组一次性动作：

| 动作 | 用户选定款 | 帧数 | 触发方式 |
| --- | --- | ---: | --- |
| 伸懒腰 `stretch` | B · 弓背伸展 | 12 | 静置时随机低频 / 手动预览 |
| 舔毛 `groom` | B · 伸舌慢舔 | 11 | 静置时随机低频 / 手动预览 |
| 磨爪 `scratch` | A · 交替磨爪 | 6 | 静置时随机低频 / 手动预览 |
| 趴下 `lieDown` | A · 缓缓趴下 | 7 | 静置时随机低频 / 手动预览 |
| 翻肚 `roll` | C · 原地侧滚 | 16 | 静置时随机低频 / 手动预览 |
| 启动迎接 `greet` | A · 摇尾迎接 | 6 | 正常启动时自动播放 / 手动预览 |
| 睡醒叫醒 `wakeUp` | B · 伸腰苏醒 | 12 | 打盹一段时间后自动醒来 / 手动预览 |

- 七种动作均提供 A/B/C 动态候选；用户完成混合选型后，四个替换项逐组导出并通过真实 Electron 专项，正式帧与所选候选逐像素一致。
- 用户选定的 14 组 83 帧全部保留；过渡优化只新增 20 帧，当前为 **14 组 103 帧**，原生尺寸仍为 76×68。
- 新帧继续使用原生调色板和统一、连续的外描边生成链；缩放使用最近邻，不进行 RGB 插值。
- 随机动作只在安静坐姿、未拖拽且未播放其他动作时触发；不会抢占携带姿态。
- 设置中心提供随机自然动作开关、较低 / 标准 / 较高三档频率和七个手动预览按钮；关闭随机后仍可预览，预览会自动恢复暂停或隐藏状态。
- 启动迎接和睡醒叫醒分别验证了真实自动触发路径，而非只能由测试接口手动播放。

## 4. 完整优化轮

- **携带帧边界**：修正无需缩小时未重新居中的导出问题，6 张携带帧不再裁掉底部一行外描边；全 103 帧增加尺寸、调色板、透明通道、单连续轮廓、触边和引用审计。
- **气泡定位**：气泡位于猫咪下方时尾部自动翻到上侧，贴近左右边缘时尾部水平跟随猫咪；时段台词显示“清晨 / 午后 / 傍晚 / 夜晚”，不再只显示“时段”。
- **真实结果反馈**：设置保存改为等待真实写入结果；自启设置后回读系统状态。磁盘保存或自启失败会显示明确错误，不再报告假成功。测试中的自启使用隔离模拟，不修改真实 Windows 启动项。
- **自然动作过渡**：保留全部用户选定关键帧，只新增 20 张桥接帧。最大相邻帧重心跳变由 8.96 降为 4.25 原生像素；审计增加 4.5 像素和 42% 变化率阈值。旧帧顺序及原生 / 六倍源图哈希保留检查通过。
- **工程维护**：设置探针拆分为 `src/main/settings-probe.ts`；行为矩阵逐项写入 JSON 和文本摘要，中断也保留证据；删除无引用 `walk_strip.png`；新增 `audit:assets`、`audit:transitions`、`check`、`smoke`、`verify` 命令。
- **依赖安全**：Electron 33.4.11 升至 45.4.1，electron-builder 25.1.8 升至 26.18.0；TypeScript 保持 5.9.3。仅对 `app-builder-lib` 与 `@electron/universal` 定向覆盖 minimatch 11.0.9，官方 npm audit 从 19 项降为 **0 项**，未执行强制修复或降级。
- **打包兼容**：electron-builder 26 改用原生压缩处理，旧 7za shim 仅在旧依赖存在时启用；打包进程按需补入 Windows PowerShell 路径，不修改系统环境变量。移除 npm 误写入的项目自引用依赖。
