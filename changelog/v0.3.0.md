# CalicoPet v0.3.0 更新日志

> 发布日期：2026-10-31
> 本版本为**纯优化版本**：不新增用户功能、不改变交互契约，集中处理渲染调度、动画状态、坐标一致性、物理时间基准和测试可靠性。

## 一句话总结

渲染循环从“永久 60Hz”改为按工作负载调度，修正了休息时仍播放走路动画的问题；绘制、命中与原生窗口现在共用同一坐标基准。开发构建与便携版产物的 **23 项行为用例均全部通过**，拖拽窗口漂移和窗口同步误差均为 **0px**。

---

## 渲染与性能

1. **按需帧调度**
   - 拖拽、跟随、漫游、落体等真实运动仍使用 60Hz。
   - 静止时按当前动画自身帧率运行（sit 2.2fps、sleep 1.4fps、眨眼 8fps）。
   - 暂停时完全停止循环，由配置、输入、气泡/提醒等事件唤醒。
   - 修复了透明失焦窗口中 `setTimeout → requestAnimationFrame` 接力可能停止的问题：低频节拍直接执行，运动帧才走 rAF。

2. **诊断与动画时钟解耦**
   - 物理仍使用 50ms 上限的稳定时间步，避免卡顿后瞬移。
   - 动画使用真实经过时间，不会因为降低空闲帧率而变慢。
   - 诊断快照改为约每 250ms 刷新，不再停留在启动时的首帧快照。

3. **空闲成本**
   - 本机开发构建、12 秒采样、统计全部 Electron 子进程：静止待机约 **5.1% 单核**，暂停约 **3.5% 单核**（后者主要是 Chromium 基础开销）。
   - v0.2.0 日志记录的开发构建静止基线为 13.6%；两次采样时长和系统负载不同，以上仅作为量级参考。
   - 同为 15 秒采样的慢速漫游：优化前 **44.6%**，优化后 **32.3%** 单核。

## 动画与行为修正

- 新增 `PetController.isMoving`，动画只看“是否真的在移动”，不再从行为模式推断。
- 漫游到达目标后休息、跟随到达鼠标后停下时，不再原地播放走路循环。
- 新增 `gait-anim` 回归用例：静止为 `sit`、漫游中为 `walk`、切回静止恢复 `sit`。
- 拖拽抛出速度改为基于指针时间戳的 px/s，而不是“每帧像素 × 固定系数”；释放前停滞超过 90ms 不再继承旧速度。
- 落体水平阻尼按秒计算，压扁回弹改为线性时间衰减，高刷新率与 60Hz 显示器手感一致。

## 坐标与命中

- 画布改为覆盖整个宠物窗口，透明内边距只由绘制阶段应用一次；修复了此前 canvas CSS offset 与 `draw()` 内部 translate 叠加造成的双重偏移和右下裁切。
- 新增 `renderMetrics()`，绘制和命中共享同一套呼吸、压扁、底部锚点计算；命中检测会逆向映射回精灵像素空间，因此压扁时点击区域也跟随实际轮廓。
- 窗口原点不再等异步 IPC 回显才更新：渲染器按与主进程相同的公式同步推进坐标，旧回显在运动期间被忽略，避免一帧坐标倒退。
- 拖拽位置在指针事件中按 12ms 节流直接上报，不再只等下一帧。
- 实测：拖拽路径 1:1、无回退；窗口同步最大误差 **0px**；像素命中区域完整落在绘制区域内。

## 配置与稳定性

- 位置持久化（`x` / `y` / `facing`）不再触发窗口 resize、托盘菜单重建和配置 IPC；只改真正需要的字段。
- 缩放和置顶只在值变化时调用原生接口。
- 新增渲染器加载失败、主框架加载失败日志，以及导航和新建窗口拦截；本地桌宠不再可能被页面导航带走。
- `__petTest` 只在自动化运行时安装。生产模式实测 `typeof window.__petTest === "undefined"`，页面不再暴露可驱动拖拽或修改配置的调试入口。
- 测试用户目录通过 `PET_USER_DATA_DIR` 显式隔离；不再读取或依赖用户真实的 `%APPDATA%\CalicoPet\pet-config.json`。

## 工程与测试

- `smoke.ps1` / `verify-behaviour.ps1` 自动清理宿主注入的 `ELECTRON_RUN_AS_NODE`、`NODE_OPTIONS`，避免 Electron 被当作 Node 启动。
- 行为脚本移除 `-NoNewWindow`，兼容宿主中大小写重复的代理环境变量。
- 新增 `hit-grid` 用例：命中剪影必须包含于绘制矩形；同时修正了原先用“包围盒宽高相等”判断剪影、导致永远误报的阈值。
- 新增 `gait-anim` 用例，行为矩阵从 21 项扩展到 23 项。
- 漫游平滑度用例改为同时统计横向和纵向路径，避免随机目标恰好在同一条竖线上时误判“没有移动”。
- 拖拽探针在测量前等待窗口同步完成，并输出实际/渲染坐标明细；排除了设置阶段 IPC 与测量阶段混淆造成的假失败。
